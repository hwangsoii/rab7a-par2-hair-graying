## Paths and dependencies

Set `HAIR_RAW_DIR` to four sample directories (`Black1`, `Black2`, `Grey1`,
`Grey2`), each containing `filtered_feature_bc_matrix/`. The deposited flat
triplets must first be arranged into that expected Cell Ranger directory
layout without changing their contents. `HAIR_DATA_DIR`, `HAIR_PROCESSED_DIR`,
`HAIR_KC_DIR`, `HAIR_FIGURE_DIR` and `HAIR_RESULTS_DIR` override local paths.
Never commit a machine-specific `config.local.R` or generated Seurat object.

The internal scripts use R 4.3.3, Seurat 5.2.1 and plotting packages listed in
`sessionInfo.txt`; scripts 05/06 also use digest and jsonlite. Use the external
README for the smaller standalone plotting dependencies. Package versions and
stochastic steps may affect a full fresh reconstruction. No fresh full-pipeline
equivalence is claimed by this packaging update.
