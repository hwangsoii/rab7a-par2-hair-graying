# Supplementary analysis code

These scripts reproduce the single-cell panels in Figure 1 and Supplementary
Figures S1-S2. The main cohort comprises four 10x Genomics libraries from two
paired donors, with one black-hair and one gray-hair sample per donor.

## Scripts

| Script | Purpose |
| --- | --- |
| `config.R` | Configurable paths, palettes and plotting helpers |
| `01_analysis_pipeline.R` | QC, CCA integration, dimensionality reduction, clustering and cell-type annotation |
| `02_keratinocyte_analysis.R` | Keratinocyte re-clustering, KRT35/KRT85 selection and differential expression |
| `03_make_Fig1.R` | Figure 1B-E and Figure S1C-E source panels |
| `04_make_SuppFig1.R` | Figure S1A-B and Figure S2A-B source panels |
| `external_cohort/01_make_Figure_S2B.R` | Standalone Figure S2B panel and statistics from released values |

Figure 1A and Figure 1F are not generated by these scripts.

## Dependencies

The reported analysis used R 4.3.3, Seurat 5.2.1, dplyr 1.1.4, ggplot2 3.5.2,
patchwork 1.3.1, ggpubr 0.6.1, ggrepel 0.9.6, cowplot 1.2.0 and Matrix 1.6.5.
Seurat 5 or later is required.

## Inputs and paths

The main scripts read four Cell Ranger `filtered_feature_bc_matrix` directories:
`Black1`, `Black2`, `Grey1` and `Grey2`. Paths are configured through
environment variables; no workstation-specific path is required.

| Variable | Purpose |
| --- | --- |
| `HAIR_BASE_DIR` | Project root and default output root |
| `HAIR_RAW_DIR` | Directory containing the four sample folders |
| `HAIR_DATA_DIR` | Working data root |
| `HAIR_PROCESSED_DIR` | Integrated and annotated objects |
| `HAIR_KC_DIR` | Keratinocyte sub-analysis objects |
| `HAIR_FIGURE_DIR` | Generated figures |
| `HAIR_RESULTS_DIR` | Generated statistics tables |
| `HAIR_EXTERNAL_S2B_SOURCE` | Optional override for the released Figure S2B table |

## Run order

```sh
export HAIR_BASE_DIR=/path/to/project_root
export HAIR_RAW_DIR=/path/to/cellranger_samples
export HAIR_DATA_DIR=/path/to/working_data

Rscript 01_analysis_pipeline.R
Rscript 02_keratinocyte_analysis.R
Rscript 03_make_Fig1.R
Rscript 04_make_SuppFig1.R
```

The standalone external-cohort panel can be run from the repository root:

```sh
Rscript supplementary_code/external_cohort/01_make_Figure_S2B.R
```

## Manuscript panel map

| Panel | Content | Script |
| --- | --- | --- |
| Figure 1B | UMAP of nine annotated cell populations | `03_make_Fig1.R` |
| Figure 1C | UMAP of keratinocyte subclusters | `03_make_Fig1.R` |
| Figure 1D | KRT35/KRT85-enriched keratinocyte differential expression | `03_make_Fig1.R` |
| Figure 1E | RAB7A expression in internal KRT35/KRT85-enriched keratinocytes | `03_make_Fig1.R` |
| Figure S1A | Melanocyte marker comparison | `04_make_SuppFig1.R` |
| Figure S1B | RAB GTPase screen | `04_make_SuppFig1.R` |
| Figure S1C-E | KRT31, KRT35 and KRT85 feature plots | `03_make_Fig1.R` |
| Figure S2A | RAB7A across nine cell populations | `04_make_SuppFig1.R` |
| Figure S2B | RAB7A in the external KRT35/KRT85-enriched subset | `04_make_SuppFig1.R` or standalone external script |

Figure 1D uses the Bonferroni-adjusted `p_val_adj` returned by
`Seurat::FindMarkers`. Figures S1A, S1B and S2A apply Bonferroni correction over
the tested genes or cell populations.

See `external_cohort/README.md` for the external source, sample mapping,
selection rule and cell counts.
